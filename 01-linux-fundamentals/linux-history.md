# Linux Fundamentals

## 1. What is Linux?

Linux is an open-source, Unix-like operating system kernel.
It manages hardware and software resources and provides
the foundation for Linux-based operating systems.

Examples:
- Ubuntu
- Debian
- Red Hat Enterprise Linux
- Fedora
- Kali Linux
- Arch Linux

## 2. What is an Operating System?

An operating system is system software that acts as an
interface between users, applications and hardware.

Responsibilities:
- Process management
- Memory management
- File management
- Device management
- Security
- Resource allocation

Examples: Linux, Windows, macOS and UNIX.

## 3. History of Linux

- 1969: UNIX was developed at AT&T Bell Labs.
- 1983: Richard Stallman started the GNU Project.
- 1991: Linus Torvalds developed the Linux kernel.
- 1992: Linux was relicensed under the GNU GPL.
- 1993: Debian and Slackware were released.
- 1994: Linux kernel 1.0 was released.
- 2004: Ubuntu was first released.

## 4. What is UNIX?

UNIX is a family of multitasking and multiuser operating
systems originally developed at AT&T Bell Labs in 1969.

Examples:
- AIX
- HP-UX
- Solaris
- BSD

## 5. What is GNU?

GNU stands for GNU's Not Unix.

It is a free software project started by Richard Stallman
in 1983 to develop a free Unix-like operating system.

Examples of GNU tools:
- Bash
- GCC
- GNU Coreutils
- GNU Make

## 6. What is the Linux Kernel?

The kernel is the core component of an operating system.

Responsibilities:
- Process management
- Memory management
- Device management
- File system management
- Network management
- Hardware communication

## 7. What is a Linux Distribution?

A Linux distribution is an operating system built around
the Linux kernel with system utilities, libraries,
package managers and applications.

Examples:
- Ubuntu
- Debian
- Fedora
- Red Hat Enterprise Linux
- Kali Linux
- Arch Linux

## 8. Features of Linux

1. Open source
2. Multiuser
3. Multitasking
4. Secure
5. Portable
6. Stable
7. Networking support
8. Customizable
9. Automation support

## 9. Linux Architecture

Main layers:

1. Hardware
2. Kernel
3. System libraries
4. Shell
5. Applications

## 10. Importance of Linux in DevOps

Linux is widely used in DevOps for:

- Server administration
- Cloud computing
- Application deployment
- Docker containers
- Kubernetes
- CI/CD pipelines
- Shell scripting
- Monitoring and troubleshooting
