## About This Repository

Welcome to my **Linux Learning Repository**!

This repository documents my journey of learning Linux from fundamentals to practical system administration and DevOps tasks.

As a Computer Science and Engineering graduate specializing in Cyber Security, I am preparing for an entry-level DevOps role. I created this repository to strengthen my Linux fundamentals, develop practical command-line skills, and prepare for real-world DevOps responsibilities and technical interviews.

The notes are organized topic by topic, with explanations, commands, examples, practical scenarios, exercises, and interview questions.

## Learning Objectives

- Understand Linux architecture and operating system fundamentals.
- Work confidently with Linux commands.
- Manage files, directories, users, and permissions.
- Monitor and troubleshoot Linux processes.
- Understand networking and connectivity.
- Manage disk space and software packages.
- Manage services using systemd.
- Analyze system and application logs.
- Automate tasks using Bash shell scripting.
- Perform practical Linux tasks used in DevOps environments.
- Prepare for Linux and DevOps technical interviews.
